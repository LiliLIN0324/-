# 泡泡龙 · Bubble Blast AI

复刻经典泡泡龙：六边形网格、同色消除、悬空掉落。关卡由 AI 生成，每打一炮还有一句 AI 解说。

纯前端 canvas 游戏，无后端；AI 不可用时自动回退到随机关卡，照样能玩。

---

## 玩法

- 鼠标或键盘左右瞄准，发射当前颜色的泡泡
- 3 个及以上同色相连即消除，失去支撑的泡泡会整串掉落
- 越界到底线即失败；场上每 10 发有概率出现炸弹泡泡
- 预判提示：下一颗泡泡的颜色提前显示

## AI 在哪里

| 能力 | 实现 | 回退 |
|---|---|---|
| 关卡生成 | Gemini 按 JSON Schema 输出 12×8 网格颜色分布 | 随机生成 |
| 每次射击的点评 | 结合局面生成一句解说 | 不显示 |

`services` 中的两个函数都做了 JSON 解析容错，解析失败不会卡住游戏。

## 本地运行

```bash
npm install
npm run dev
```

复制 `.env.example` 为 `.env.local` 并填 `GEMINI_API_KEY` 才会启用 AI；不填即为纯本地游戏。

## 结构

```
App.tsx              画布、主循环、状态机
utils/gameLogic.ts   网格坐标、邻居查找、连通块、悬空检测
constants.ts         网格尺寸、颜色、几何参数
```

## 部署

任意静态托管：`npm run build` 后把 `dist/` 推上去即可。

## 已知限制

- 无音效
- 单局分数只存在内存中，刷新即清零
